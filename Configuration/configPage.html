EnhancedFin

Ratings, watchlist, follows and release calendar. API keys stay on this server: clients never see them. Changes apply immediately, no restart needed.

TMDB (required)

Metadata, search, trending and release dates. Free: create an account on themoviedb.org, then Settings → API → "API Key" (v3, not the read access token).

MDBList (optional)

Rotten Tomatoes scores on media pages. Free account on mdblist.com, then Preferences → API key (1,000 requests a day, scores are cached for 7 days).

Seerr (optional)

The address at which this Jellyfin server reaches Jellyseerr or Overseerr.
In Seerr: Settings → General → API Key. Enables availability and requests.

ASS subtitles

Rewrites your files. After each library scan, embedded ASS tracks of .mkv files are converted to external .srt files and removed (stream copy, no re-encoding). For players that cannot render ASS; ASS styling is lost.
The original is kept as a hidden ".file.mkv.ass-backup" next to it. Doubles disk usage until you delete the backups.
